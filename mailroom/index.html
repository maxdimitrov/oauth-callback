mailroom

mailroom is a personal tool that keeps its owner's own Gmail inboxes organized. It applies labels from a small fixed list, archives mail that does not need attention, and logs every change so it can be undone. The same Google OAuth client is used by the owner's local Gmail assistant tools, which read and triage the same mailboxes.

It is not a public service. It only accesses Google accounts belonging to its owner, who authorizes each one individually.
